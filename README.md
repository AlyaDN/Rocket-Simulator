Rocket Trajectory Simulation

This project is a Python-based rocket trajectory simulation. It models the motion of a rocket during flight and generates a graph showing how the rocket's trajectory changes over time.

Project Files

- `rocket_simulation.py` — Main Python program containing the rocket simulation.
- `requirements.txt` — Python libraries required to run the simulation.

How It Works

The Python program uses mathematical and physical calculations to simulate the rocket's flight.

The simulation calculates how the rocket's motion changes during flight and uses the results to generate a trajectory graph.

How to Run

1. Download or clone this repository.
2. Install the required Python libraries: pip install -r requirements.txt
3. Run the simulation: python rocket_simulation.py

   The simulation produces a trajectory graph
